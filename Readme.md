# حاسبة التاريخ والوقت

موقع عربي يوفر مجموعة من الحسابات المتعلقة بالتاريخ والوقت، مع دعم ثلاثة أنظمة تاريخ: **الغريغوري (الميلادي)**، **اليولياني (الميلادي الشرقي)**، و**تقويم أم القرى (الهجري الرسمي)**.

🔗 **الموقع:** [datetimecalcar.netlify.app](https://datetimecalcar.netlify.app)

## المميزات

-  حساب الفرق بين تاريخين
-  حساب الفرق بين وقتين
-  تحويل تاريخ واحد بين الأنظمة الثلاثة + معرفة يوم الأسبوع
-  عرض رزنامة أي شهر (مع التنقل بين الأشهر)
-  حساب تاريخ بعد/قبل فترة زمنية محددة
-  حساب وقت بعد/قبل فترة زمنية محددة
-  عرض رزنامة أي شهر
-  قابل للتثبيت كتطبيق (PWA)


## التقنيات المستخدمة

- [Vue 3](https://vuejs.org/) (Composition API + `<script setup>`)
- [Vite](https://vitejs.dev/)
- Netlify للنشر



## التشغيل محليًا

```bash
npm install
npm run dev
```

### البناء للنشر

```bash
npm run build
```

## المرجعية الحسابية

- التحويل بين الغريغوري واليولياني يعتمد على **العدد اليولياني للأيام (JDN)**.
- تقويم أم القرى الهجري يُحسب عبر `Intl.DateTimeFormat` (`islamic-umalqura`) عند توفره في المتصفح، مع تقريب حسابي (خوارزمية هجرية اصطلاحية) كخيار احتياطي عند عدم الدعم.
